# Prompt Library — копи-пейст готовый

> Все 12 промптов с уже заполненными плейсхолдерами под профиль:
> **33 года, AI Visual Creation, 6 подписчиков, без бюджета, UTC+2.**
>
> Используй с Claude Sonnet/Opus 4.x или GPT-5. Перед каждым промптом — короткая инструкция, как использовать результат.

---

## #1 — Выбор ниши

**Когда:** один раз на старте или при пересмотре направления (раз в квартал).

```
Мне 33 года и я интересуюсь AI visual creation.
Дай мне 5 ниш для Shorts с наивысшим CPM.
Включи: конкуренцию, реальные доходы при 10K подписчиков и с какой
начать СЕГОДНЯ без денег.
Отсортируй по скорости монетизации.
```

---

## #2 — Сценарий 45 секунд

**Когда:** перед каждым новым видео. Замени тему в первой строке.

```
Напиши сценарий для короткого видео длительностью 45 секунд о
[ТЕМА: например, "Krea AI vs Midjourney для скорости"]
для аудитории "креаторы и фрилансеры 25–40, без технического бэкграунда".

Включи:
- Хук в первые 3 секунды
- 3 ключевых пункта с данными (конкретные цифры, кейсы)
- Финальный призыв к действию, который спровоцирует комментарии

Тон разговорный, короткие фразы, без воды.
```

---

## #3 — 20 хуков

**Когда:** раз в неделю, чтобы был запас на 7 видео + резерв.

```
Дай мне 20 хуков из 1 строки для Шортса о AI visual creation.
5 о любопытстве. 5 шокирующих. 5 прямых вопросов. 5 жестоких обещаний.

Каждый хук должен содержать меньше 10 слов и звучать так, как сказал бы
настоящий человек. Без штампов "сегодня я расскажу".

Под каждым хуком — 1 строка о том, для какой темы AI visual creation он подходит.
```

## #4 — 15 заголовков

**Когда:** после готового сценария, перед публикацией.

```
Сгенерируй 15 заголовков для Шортса на тему:
[ВСТАВЬ КРАТКОЕ ОПИСАНИЕ ВИДЕО, 1–2 строки]

5 с номером. 5 с вопросом. 5 с эмоциональным напряжением.
Менее 60 символов каждый.

Укажи, какой имеет наибольший потенциал виральности и почему
(в 3 пунктах: эмоция, конкретика, CTR-механика).
```

## #6 — Перестройка под удержание

**Когда:** если у видео низкое удержание (<60% при тесте).

```
Перестрой этот сценарий для МАКСИМАЛЬНОГО удержания в Shorts.

Добавь:
- Открытую петлю в начале (намёк на твист в конце)
- Клингер на 15-й секунде ("дотерпи до X — там самое важное")
- Неожиданный поворот на 30-й секунде (drama, контр-факт, инсайдер-инфа)
- Закрытие петли в финале (раскрытие обещанного из начала)

Дай оптимизированную версию по секундам в формате [0:00–0:03 — описание].

Сценарий:
[ВСТАВЬ СВОЙ СЦЕНАРИЙ]
```

## #7 — SEO-описание

**Когда:** после публикации сценария, перед загрузкой в YouTube.

```
Создай идеальное описание для Shorts на тему:
[ВСТАВЬ КРАТКОЕ ОПИСАНИЕ ВИДЕО]

Включи:
- Первую строку с точной ключевой фразой (для поиска)
- 3 строки с хуками (по одному на каждый ключевой пункт видео)
- 1 строку с CTA на подписку
- 1 строку с вопросом для комментариев
- 15 хэштегов: 5 крупных (1M+ постов), 5 средних (100K–1M), 5 нишевых (<100K)
```

## #8 — 30 идей на 30 дней

**Когда:** в конце каждого месяца — заготовка на следующий.

```
Дай 30 идей для Shorts на тему AI visual creation на следующие 30 дней.

Каждая идея с:
- Заголовком (до 60 символов)
- Хуком из 1 строки
- Уникальным углом

Не повторяй концепции. Микс по неделям:
- Неделя 1: образовательный контент
- Неделя 2: вирусный/трендовый
- Неделя 3: провокационный
- Неделя 4: микс + ретроспектива

Учитывай, что у меня 6 подписчиков на старте — приоритет на удержание + поиск.
```

## #9 — Длинный контент → 10 Shorts

**Когда:** есть длинное видео, гайд, статья или подкаст-фрагмент 10+ мин.

```
Проанализируй этот длинный сценарий/контент и извлеки 10 независимых Shorts.

Каждый из них:
- Свой собственный хук (никаких "как я говорил выше")
- Закрытое начало и конец (можно смотреть отдельно)
- 30–60 секунд
- Свой угол (не дублировать смысл)

Контент:
[ВСТАВЬ ИСХОДНИК]

Формат вывода: таблица номер | хук | тема | длительность | ключевая идея.
```

## #10 — Монетизация

**Когда:** один раз на старте + пересмотр каждые 2 месяца.

```
Я создатель Shorts о AI visual creation с 6 подписчиками.

Дай мне 7 способов монетизировать ПРЯМО СЕЙЧАС.

Сортируй по: реалистичный доход в первый месяц + лёгкость внедрения.

Без теории. Конкретные примеры:
- название платформы/программы
- что делать в день 0
- ожидаемый доход в первый месяц
- что нужно для масштабирования до 1K подписчиков
```

## #12 — Календарь публикаций

**Когда:** раз в месяц на следующие 30 дней.

```
Создай календарь публикаций на 30 дней для канала Shorts о AI visual creation.

Учитывай:
- Часовой пояс автора: UTC+2 (Berlin)
- Целевая аудитория: US East Coast + EU
- Стартовая база: 6 подписчиков
- Цель к 30-му дню: 300–600 подписчиков

Включи:
- Лучшее время публикации по дням недели (с обоснованием)
- Оптимальная частота (1/день или 2/день, когда переходить)
- Микс форматов по неделям (educational / viral / provocative / personal)
- Слоты-исключения (когда НЕ публиковать)
- Правило ретроспективы (когда анализировать метрики)
```
